# AspireAI

AspireAI is an AI-powered growth companion built during our hackathon. The idea behind this project is simple—we want to help people stop wasting time searching for the right learning resources and instead provide them with a personalized path toward their goals.

Most recommendation systems focus on increasing screen time. We wanted to build something different. AspireAI focuses on helping users grow by understanding who they are, where they want to go, and what they should learn next.

## What AspireAI Does

- Understands the user's career goals and interests
- Creates a personalized learning roadmap
- Recommends the best learning resources for each topic
- Suggests practical challenges to improve skills
- Tracks progress throughout the learning journey
- Supports users with an AI mentor for doubts and guidance

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python (Flask)
- **Database:** MySQL
- **AI:** OpenAI API (Planned)

## Why We Built This

Learning today is overwhelming because there is too much content available and very little guidance. AspireAI aims to solve this by acting as a personal growth companion that recommends the right content at the right time based on the user's goals and progress.
